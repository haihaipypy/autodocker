# 企业微信配置

> 返回 [README](../README.md) · 其他渠道：[飞书](feishu.md) / [Telegram](telegram.md) / [钉钉](dingtalk.md)

配好之后，发现镜像有新版本会往企业微信推一张卡片，**点卡片上的按钮直接重建容器**，手机上也能操作。

用的是**智能机器人 + 长连接**，全程不需要公网 IP、不用域名、不用备案、不用内网穿透，也不用加解密。
卡片由程序直接生成，**不用去后台搭模板**。

配置需要一个**能创建智能机器人的账号**（默认全员可创建，管理员可在后台按部门收紧）。

| 步骤 | 在哪做 | 拿到什么 |
|---|---|---|
| 1 建机器人 | [管理后台](https://work.weixin.qq.com/wework_admin/frame) → 智能专区 → 智能机器人 → 创建 | 一个机器人 |
| 2 开长连接 | 创建页 → API 配置 → 使用长连接 | 启用长连接 |
| 3 授权能力 | 创建页 → 使用模式 → 可使用权限 → 去授权 | 消息、通讯录 |
| 4 取凭据并保存 | 同一处取 BotID / Secret，填进设置页 | 长连接建立 |
| 5 取会话 | 企业微信里 @ 机器人 + 设置页 | 会话 ID |
| 6 测试 | 设置页 | 验证按钮能点 |

---

## 一、配置流程

### 1. 建机器人

打开[企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame)，点 **智能专区** → **智能机器人** → 创建 → 新建机器人。

创建方式选 **「API 模式创建」**，名字随意。

也可以在电脑端或手机端 **工作台 → 智能机器人 → 创建机器人**（客户端需 v5.0 以上）。

### 2. 开启长连接

还在创建页，右侧 **API 配置** 里选 **「使用长连接」**，保存。

### 3. 授权能力

往下滚到 **使用模式**：

- **使用方式** 选 **「多人使用」** —— 选「仅个人使用」的话，群里其他人点卡片按钮没反应；
- **可使用权限** 点右边的 **「去授权」**，勾上：

| 权限 | 用途 |
|---|---|
| 消息 | 收发消息、推卡片 |
| 通讯录 | 识别成员与群 |
| 用户信息 | 默认已授权，不用操作 |

文档、邮件、待办、日程、会议、微盘都不要勾 —— 本服务不读这些数据。

授权完回到页面，确认「消息」「通讯录」都显示已授权。

### 4. 取两个值，填进设置页

同一页面上有：

| 值 | 填到设置页的哪一格 |
|---|---|
| `BotID` | 机器人 BotID |
| `Secret`（长连接专用） | 长连接 Secret |

> **Secret 是「长连接专用」那个**，不是接收 URL 模式的 `Token` / `EncodingAESKey`。三个长得像，填错了会一直连不上。

填完点底部「保存设置」。几秒内右栏「当前状态」会变成 **已配置，长连接在线**。

没变成在线的话，那一行会把原因写出来（比如订阅被拒绝、网络不通）。

### 5. 取接收会话

1. 把机器人**加进目标群**（或直接在单聊里用它）；
2. 在群里 **@机器人 说一句话**（单聊就直接发一句）；
3. 回到设置页点 **「读取会话」**，从列表里点一条。

> **只有企业内部群能加机器人。** 互联群、上下游群、外部群都加不进去，
> 硬拉进去也收不到消息 —— 想让外部的人也能点按钮，只能走单聊。

会话 ID 会存进数据库，之后重启、装新包都还在 —— 只有新加了一个群才需要再 @ 一次。

### 6. 发一张测试卡片

点 **「发送企业微信测试卡片」**，卡片会发到刚才那个会话。

再点一下卡片上的**任意按钮** —— 卡片当场变成「按钮链路正常」，才算「发得出去 + 收得回按钮」两条链路都通。

## 二、收到新版本之后

### 1. 提醒长什么样

卡片上有三行信息（容器、镜像、版本或摘要）和三个按钮：

| 按钮 | 作用 |
|---|---|
| 立即更新 | 按原配置重建容器，失败自动回滚 |
| 稍后 | 本轮巡检不再提醒这个版本 |
| 忽略 | 同一个版本不再提醒，出现更高版本时仍会通知 |

### 2. 点「立即更新」之后

- 卡片立刻变成 **「正在更新」**；
- 重建完成后，**另外发一条消息**告诉你结果（成功 / 失败 / 已回滚）。

> 企业微信只允许在点击按钮后 **5 秒内** 更新那张卡片，而重建容器要几十秒。
> 所以结果是用一条新消息发的，原来那张卡片会一直停在「正在更新」——
> 这是协议限制，不是卡住了。

## 三、常见问题

| 现象 | 原因与处理 |
|---|---|
| 状态一直显示「长连接未建立」，报 `errcode=...` | BotID 或 Secret 填错，或填的是接收 URL 模式的 Token。重新复制一遍长连接 Secret |
| 状态显示「长连接未建立」，没有报错 | 机器人所在网络访问不了企业微信，或服务刚保存完还在建连，等十几秒再看 |
| 「读取会话」里没有条目 | 机器人还没在会话里收到过消息。先 @ 它说一句；也确认长连接已在线 |
| 测试卡片发不出去，提示「长连接未建立」 | 先解决连接问题，再发卡片 |
| 卡片收到了，点按钮没反应 | 检查机器人配置页的 API 模式是否为「长连接」；再看容器日志里有没有收到事件回调 |
| 卡片上的字被截断 | 企业微信对每个字段有字数上限，程序已按上限截断并加省略号，完整信息看网页「通知」标签 |

看日志时搜 `企业微信`：

```bash
docker logs autodocker 2>&1 | grep 企业微信
```
